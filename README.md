# Moje Kuchařka

Osobní kuchařka (300+ receptů, hledání, filtry, přepočet porcí, vlastní recepty).
Statický web — žádná instalace ani build, stačí `index.html` a ostatní soubory.

## Zprovoznění na GitHub Pages

1. Na GitHubu vytvoř nový repozitář (např. `moje-kucharka`).
2. Klikni **Add file → Upload files** a nahraj **obsah** této složky
   (index.html musí být přímo v kořeni repozitáře, ne uvnitř podsložky).
3. **Commit changes**.
4. Otevři **Settings → Pages**, u *Source* zvol **Deploy from a branch**,
   větev **main** a složku **/ (root)**, ulož.
5. Za minutu až dvě poběží web na `https://TVOJE-JMENO.github.io/moje-kucharka/`.

Vlastní recepty se ukládají v prohlížeči (localStorage) na daném zařízení.
